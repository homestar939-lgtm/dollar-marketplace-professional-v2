# جاهزية إصدار الشبكة المحلية — دولار ماركت بليس

**النطاق:** إصدار داخلي للشركة على شبكة LAN/Wi-Fi، وليس خدمة عامة على الإنترنت. يمكن استخدام HTTP داخل شبكة موثوقة ومعزولة؛ ينبغي تقييد الوصول بجدار الحماية وعدم تعريض API أو SSE للإنترنت العام.

## المنفذ في هذا التغيير

- مصادقة حسابات الموظفين والعملاء عبر اسم المستخدم وكلمة المرور فقط.
- حذف Google OAuth، تسجيل البريد، التحقق/إعادة تعيين كلمة المرور بالبريد، وOTP للهاتف.
- إزالة مبدّل الأدوار التجريبي وشاشات Demo من تدفق التطبيق.
- إعداد Android لاتصال API قابل للتغيير من شاشة Server Settings، وتمكين HTTP cleartext للاستخدام على LAN. يستخدم SSE العنوان المحفوظ ذاته.
- API يستمع على `0.0.0.0`، ويتطلب في الإنتاج سر JWT قوياً وCORS صريحاً لأصول الويب الداخلية.
- يتطلب seed كلمات مرور فريدة بطول لا يقل عن 24 محرفاً للحسابات الخمسة: `admin`, `warehouse`, `collector`, `accountant`, `buyer`. لا توجد كلمات مرور مشتركة ثابتة في المستودع.
- يتطلب Release توقيع APK؛ keystore المؤقت المولّد في CI مناسب للتثبيت الأولي فقط. احتفظ بمفتاح ثابت آمن لإصدارات التحديث كي تقبلها أجهزة Android كتحديث للتطبيق نفسه.

## ما يلزم قبل التعميم على أجهزة الشركة

1. تثبيت IP/DNS ثابت للخادم، فتح منفذ API في LAN فقط، وضبط Origin الويب المحدد في `CORS_ORIGINS`.
2. إنشاء PostgreSQL ونسخ احتياطي/استعادة مجرّبة، ثم تطبيق Prisma migrations قبل تشغيل seed.
3. تخزين كلمات مرور الحسابات الخمسة وسر JWT ومفتاح توقيع Android في مخزن أسرار، وتغيير كلمات المرور بعد أول دخول.
4. ضبط عنوان API الداخلي في Android Server Settings وعلى متغير GitHub `LAN_API_BASE_URL` لإنتاج APK مهيأ افتراضياً. لا تستخدم `127.0.0.1` على جهاز Android فعلي.
5. اختبار تسجيل الدخول والأدوار ودورة الطلب/الفاتورة/القبض وتقارير المالية وSSE على أجهزة فعلية عبر Wi-Fi.
6. استكمال قرارات الأعمال الخاصة بتوقيع المستندات، صلاحيات المحاسب، وإثبات التسليم والتنبيهات قبل اعتبار جميع عمليات ERP مكتملة.

## تهيئة آمنة

لا تضع كلمات المرور أو مفاتيح التوقيع في Git أو المحادثات. يطلب API في الإنتاج `NODE_ENV=production` و`DATABASE_URL` و`JWT_SECRET` بطول 32 محرفاً على الأقل، و`CORS_ORIGINS` محدداً إلى Origins LAN كاملة دون مسارات. يمرر seed كلمات المرور عبر `SEED_ADMIN_PASSWORD`, `SEED_WAREHOUSE_PASSWORD`, `SEED_COLLECTOR_PASSWORD`, `SEED_ACCOUNTANT_PASSWORD`, و`SEED_BUYER_PASSWORD`.
